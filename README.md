# Isabella XV — V5 Single Page

Una sola página vertical con scroll/snap. Cada capítulo ocupa una pantalla completa y se puede recorrer deslizando hacia abajo.

## Qué se cambió

- Una sola página, sin pestañas/pantallas independientes.
- Scroll vertical de 8 capítulos.
- Los fondos/elementos visuales proceden directamente de los recortes del mockup proporcionado.
- Los textos, botones y funciones interactivas son HTML/React.
- Cuenta regresiva real hasta 19/12/2026 7:00 PM (hora Colombia).
- Google Maps para la ubicación.
- WhatsApp para confirmar asistencia.
- Menú y navegación lateral para saltar a capítulos.
- Sin música.
- Sin línea de tiempo.
- Responsive para móvil.

## Ejecutar

```bash
npm install
npm run dev
```

Después abre la dirección que muestre Vite, normalmente:

`http://localhost:5173`

## Nota sobre el arte

El mockup original contiene texto integrado dentro de sus imágenes. Esta V5 coloca encima el contenido HTML interactivo para que los botones y funciones funcionen. Para una versión final pixel-perfect con absolutamente ningún texto duplicado, habría que producir una versión limpia de cada fondo (sin tipografía) conservando únicamente ilustraciones y decoración.
